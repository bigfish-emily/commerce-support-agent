# Merchant Rules

## Health Beauty Merchant Rule

Health and beauty products require stricter after-sales review because complaints
may involve hygiene, damaged packaging, missing items, or safety concerns. The
Agent may create a support case for delayed or low-review orders, but refund,
replacement, or coupon decisions should go through human confirmation unless the
merchant policy tool returns explicit approval.

For delivered health_beauty orders, address changes and direct cancellation are
not allowed. The Agent should explain the fulfillment boundary and offer a refund
or support review path instead.

## Electronics Merchant Rule

Electronics and computer accessories often require serial number, warranty status,
and product condition checks before refund, exchange, or return-label creation.
When these fields are missing, the Agent should ask for clarification or create a
review case rather than approving a refund directly.

## High Value Order Rule

Orders with payment value greater than or equal to 300 require human review before
refund, compensation, cancellation override, return label issuance, or seller
penalty. The Agent can prepare a decision summary, but the write action must be
confirmed by an authorized support role.
